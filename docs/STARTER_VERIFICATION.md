# Verifikasi boilerplate

Baseline diperiksa 20 Oktober 2026; integrasi enam skill frontend diperiksa 21 Oktober 2026 pada macOS ARM64, Node 22.23.2 / npm 10.9.8. Scope: fondasi frontend reusable beserta contoh teknis koleksi item yang disetujui pengguna. Hasil ini tidak menyatakan aplikasi bisnis, backend, atau proyek klien telah diterima.

## Reproduksi dan evidence

```sh
npm ci
npm run check
npm run build
npx playwright install chromium webkit
npm run test:browser
npm run preview
```

Browser sesi ini tersedia melalui PLAYWRIGHT_BROWSERS_PATH pada direktori sementara. Tanpa variabel itu, instalasi Playwright memakai cache default pengguna. Browser JSON berada pada test-results/browser.json. Capture visual 12 file serta production-evidence.json berada di .impeccable/review. Semua merupakan evidence pengujian lokal dan tidak disalin oleh generator proyek. Probe skill berada di direktori sementara terpisah dan tidak menjadi produk contoh baru dalam starter.

## Batas bukti

Pengujian render tidak mencakup seluruh kombinasi props, locale, atau input IME OS fisik. Pengujian WebGL menggunakan browser pada mesin ini, termasuk software rendering Chromium; belum membuktikan semua GPU/mobile nyata. Penanganan context loss tersedia dalam kode, tetapi tidak diinjeksi sebagai kegagalan GPU fisik dalam run ini. Tidak ada benchmark Core Web Vitals/perangkat pengguna, autentikasi, otorisasi, database multi pengguna, integrasi backend/provider nyata, atau deployment publik yang diuji. Setelah membuat fitur klien, tambahkan acceptance untuk scope, model, data, dan perangkat sebenarnya.

## Integrasi skill frontend — 21 Oktober 2026

Enam sumber skill yang diminta pengguna ditinjau dan disertakan project-local, dipatok ke commit penuh, lengkap dengan 125 file asli/referensi serta lisensi/notice. docs/AI_SKILLS.md mencatat sumber dan penyesuaian Vite/Query/Radix, termasuk menghindari Next.js-only API, mengganti pustaka query tanpa kebutuhan, reinitialisasi ui-v1, serta melewati typecheck build. AGENTS.md dan skill starter mengarahkan AI memilih panduan sesuai tugas.

- npm run skills:check lulus; dua negative-control tests tambahan membuktikan instruksi berubah, resource hilang dan file asing ditolak. Total test tooling sekarang 9.
- shadcn CLI 4.22.1 info --json mengenali Vite, Tailwind v4, Radix, Lucide dan 53 komponen pada shared/ui. Perintah docs untuk Button/Dialog/Input berhasil, dan halaman resmi yang dikembalikan dibaca. Tidak ada preset/component overwrite.
- Helper Python with_server.py diuji sebagai black box: satu server file lokal dimulai, readiness/request diperiksa, command selesai, dan port/server ditutup. Ini bukan pengujian browser Python. Jalur browser utama tetap Playwright Test/TypeScript.
- npm run check (70 unit + 9 tooling), build dan 166 test browser lulus. Test baru menjaga dependency/model 3D tidak dimuat oleh homepage. Screenshot kegagalan dan trace tersedia ketika test gagal.
- Salinan proyek baru 21 Oktober lulus: enam skill/manifest/routing/components.json ikut tersalin, npm ci --offline memasang 325 package, check (70 unit + 9 tooling) dan build lulus. CLI info pada direktori baru mengenali 53 komponen dengan alias mengarah ke shared/ui proyek baru. File skill tidak masuk dist.
- Forward test independen berhasil menghasilkan proposal edit judul yang memakai model/API/UI/tipe/test plan sesuai stack, dengan enam panduan dipilih dan dijelaskan, tanpa implementasi, instalasi, server atau perubahan source. Skill tidak dipasang global, tidak masuk dist, dan tidak menambah dependency runtime frontend. Snapshot Vercel menyimpan tiga tautan relatif compiled AGENTS.md yang keliru dari upstream; rule individual tetap lengkap dan cara mengaksesnya didokumentasikan.
